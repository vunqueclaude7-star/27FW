## 참여 방법 (직원용)
1. 링크 접속 → 이름 · 부서 · 성별 · 연령대 입력
2. 카테고리(BAG/WALLET/ACC)별로 상품마다 **가격(싸다/적당하다/비싸다)** · **판매성(낮다/보통/높다)** 평가 + 의견(선택) 작성
3. 화면 하단 **베스트 순위 선택**에서 BAG(1~5순위) · WALLET(1~3순위) · ACC(1~3순위) 순위 선택
4. **제출하기** → 자동으로:
   - 구글 시트에 카테고리별 탭(BAG/WALLET/ACC)으로 한 사람당 한 행씩 실시간 기록
   - 카테고리별 담당 MD 메일로 요약 자동 발송 (BAG → vunque.claude6@gmail.com, WALLET·ACC → vunque.claude7@gmail.com)
   - 응답 파일도 다운로드됨 (백업용, 위 자동 전송이 실패했을 때 대비)
- 작성 중 내용은 브라우저에 자동 임시저장되어, 새로고침해도 이어서 작성 가능. 제출 완료 화면에서 "다시 작성하기"로 수정 후 재제출도 가능.
