# 27FW 시즌 품평회

## 품평 도구 링크
https://claude.ai/code/artifact/e392161c-d608-48aa-94f1-999c8ad1751b

## 공유 방법 (회원가입 불필요)
1. 아트팩트 페이지 우측 상단 **공유(Share)** 버튼 클릭
2. **General access**를 "Only you" → **"Anyone with the link"** 로 변경
3. 링크를 복사해 4명에게 그대로 전달 (Claude 로그인만 되어 있으면 참여 가능, 별도 조직/팀 가입 불필요)

> 이 도구는 서버에 데이터를 저장하지 않고, 각자 브라우저에서만 동작합니다. 그래서 별도 팀 플랜 없이도 링크만으로 공유할 수 있는 대신, 결과는 아래처럼 **파일을 모아서** 집계합니다.

## 참여 방법 (직원용)
1. 링크 접속 → 이름 · 부서 · 성별 · 연령대 입력
2. BAG(1~5순위) · WALLET(1~3순위) · ACC(1~3순위) 사진을 눌러 순위 선택
3. **제출하기** → `.json` 응답 파일이 자동 다운로드됨 (다운로드가 안 되면 화면에 뜨는 텍스트를 복사)
4. 다운로드된 파일을 카카오톡/메일 등으로 **담당 MD에게 전달**

## 결과 집계 방법 (MD용)
1. 같은 링크에서 **'결과 집계'** 탭 클릭
2. 받은 `.json` 파일들을 한 번에 여러 개 선택해 업로드 (본인 파일 포함, 최대 5개)
3. 부서 · 성별 · 연령대 필터로 잘라보며 카테고리별 순위·득표 확인
4. 필요하면 CSV로 원본 응답 내려받기
- 이 집계는 업로드한 사람의 브라우저 안에서만 계산되며 서버에 저장되지 않으므로, 새로고침하면 다시 파일을 올려야 합니다.

## 참여 대상 부서
기획팀 · 디자인실 · 품질팀 · 영업팀 · 임원 · 비주얼실 · 마케팅팀 · 신규사업부 · 사업운영팀

## 순위 선택 기준
- **BAG**: 1~5순위
- **WALLET**: 1~3순위
- **ACC**: 1~3순위

기준 정보는 **샘플명 · 예상판가**이며, 사진이 있으면 이미지로도 확인할 수 있습니다.

## 샘플·이미지 교체
지금은 예시 상품(임시 샘플명/가격)이 들어 있습니다. **실제 27FW 상품명·예상판가 목록**과, 있다면 **상품 이미지 파일**(샘플명과 동일한 파일명)을 전달해 주시면 도구에 반영해 다시 공유해 드립니다.
